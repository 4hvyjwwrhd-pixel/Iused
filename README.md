# iUsed Online

نسخة أولية حقيقية متعددة المستخدمين لنظام تسعير الموبايلات.

## المزايا
- قاعدة بيانات SQLite.
- بحث وفلترة حسب الشركة.
- المدير فقط يستطيع تسجيل الدخول.
- تعديل السعر.
- إضافة موديل جديد بترقيم تلقائي من قاعدة البيانات.
- حذف موديل.
- كل المستخدمين يشاهدون نفس البيانات على السيرفر.

## التشغيل
يتطلب Node.js 18+.

```bash
npm install
ADMIN_PASSWORD="غيّر_الرقم_السري" SESSION_SECRET="غيّر_المفتاح" npm start
```

ثم افتح:
http://localhost:3000

## مهم
الرقم الافتراضي للتجربة هو 1234 إذا لم يتم تعيين ADMIN_PASSWORD.
قبل النشر على الإنترنت يجب تغييره، وتعيين SESSION_SECRET قوي.
ملف iused.db يتم إنشاؤه تلقائياً ويحتفظ بالبيانات.
